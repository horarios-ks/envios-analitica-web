# Envíos Analítica Web

Página con el horario de correos de Analítica Web para los equipos de marca: qué llega cada día, qué revisar y cómo responder.

## Cómo se actualiza
1. Abre `datos/envios.xlsx`, edita las hojas (ver la hoja **Instrucciones**) y guarda.
2. En GitHub: entra a la carpeta `datos` → **Add file → Upload files** → sube `envios.xlsx` (reemplaza el anterior) → **Commit changes**.
3. En 1–2 minutos la web se actualiza sola.

## Links
- General (todos los equipos): `https://horarios-ks.github.io/envios-analitica-web/`
- Por equipo: agrega `#clave` al final, por ejemplo `.../envios-analitica-web/#converse`
  Claves: cat, converse, new-balance, steve-madden, hitec-merrell, fila-umbro

## Importante
La página es pública para quien tenga el link: no pongas SKUs, precios ni correos de personas en el Excel.
